# Daily Quora answers
A scheduled task drafts one answer every morning (Philippine time) as `YYYY-MM-DD.md` in this folder.

What you do (about 2 minutes):
1. Open the file for today, then open the question link in it.
2. Read the answer, change anything that doesn't sound like you, paste it into Quora and post.
3. Optional: change "no" to "yes" in the Posted column of `answered-log.md`.

Rules the drafts follow: one answer a day, a link in roughly every other answer, only prositeguide.com article links (never affiliate links), "Disclosure: it's my site" whenever a link is included.
