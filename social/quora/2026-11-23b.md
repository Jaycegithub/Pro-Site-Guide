**Question:** Will using the Jetpack plugin for WordPress improve my site's performance or make it worse?
**Link:** https://www.quora.com/Will-using-the-Jetpack-plugin-for-WordPress-improve-my-sites-performance-or-make-it-worse
**Article linked:** none (link-free answer; your profile does the work). Optional: https://prositeguide.com/law-firm-website-speed/
**Why this one:** you just did this on your own site (56 → 99 mobile), so you can answer from real experience.

## Answer (copy and paste)

```
It can do either. It depends on which parts you switch on and what else is already running on your site.

I just went through this on my own WordPress site. It started at 56 on mobile in Lighthouse (the engine behind PageSpeed Insights) and ended at 99. Jetpack was only part of the story:

- The biggest win had nothing to do with Jetpack: my server wasn't compressing files at all. Turning on gzip and page caching (I used WP Fastest Cache) took it from 56 to 85 on its own.
- Jetpack Boost then helped: generating Critical CSS and deferring non-essential JavaScript pushed it into the 90s.
- Self-hosting Google Fonts and delaying Google Tag Manager until the visitor scrolls did the rest.

Where Jetpack made things WORSE: turning on Boost's "Concatenate CSS" at the same time as my cache plugin's CSS minify broke the site's styling. Two plugins rewriting the same files is a classic conflict.

So my advice: only enable the modules you need, never run two tools that do the same job (two caches, two minifiers), and test your mobile score before and after each change, not all at once.
```
